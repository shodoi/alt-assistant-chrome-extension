Gemini Alt Text Generator 設定

この拡張機能を使用するには、Google AI StudioまたはGoogle Cloud Vertex AIで取得したGemini APIキーが必要です。

APIキーはお使いの端末内（chrome.storage.local）にのみ安全に保存され、画像のAltテキスト生成にのみ使用されます。

使用モデル

Gemini 3.8 Flash

高速かつ高精度な最新世代モデルで Alt テキストを自動生成します。

標準モデル

セキュリティとプライバシー

安心・安全設計

本拡張機能はユーザーのプライバシー保護と最小権限の原則（Least Privilege）に準拠して設計されています。

  • ✓
    端末内ローカルストレージ（chrome.storage.local）への安全な保存

    入力された API キーはお使いの端末内ローカルストレージ（chrome.storage.local）にのみ暗号化・隔離保存されます。開発者や第三者の外部サーバーに送信・保存されることは一切ありません。

  • ✓
    Google Gemini API エンドポイントへの直接暗号化通信

    Alt テキスト生成時は、ブラウザから Google の公式 API エンドポイント（https://generativelanguage.googleapis.com/*）へ HTTPS で直接暗号化通信を行います。プロキシや外部サーバーは介在しません。

  • ✓
    最小権限の原則（不要な全サイト閲覧権限の不使用）

    Web 閲覧履歴や全ページのデータを常時読み取る過剰な権限（<all_urls>）は一切要求しません。ユーザーが画像を右クリックした対象タブでのみ一時的に動作する activeTab 権限を主軸としています。
