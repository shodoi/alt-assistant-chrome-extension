# 03: スクリーンリーダー向け状態通知（aria-live ライブリージョン対応）

**What to build:** 
Altテキストの生成開始・待機中・完了・エラー発生などの状態変化を、視覚的に画面を見ることができないスクリーンリーダー利用ユーザーに対しても、`aria-live` ライブリージョンおよび適切な ARIA ロール（`role="status"`, `role="alert"` 等）を通じて自動で音声通知する。

**Blocked by:** 02: ダイアログ・モーダルのフォーカストラップとキーボード操作性（A11y）向上

**Status:** ready-for-agent

- [ ] 生成開始時に「Altテキストを生成中…」というステータスがスクリーンリーダーに通知（読み上げ）されること
- [ ] 生成完了時に「Altテキストの生成が完了しました」とプレビュー内容の要約が通知されること
- [ ] エラー発生時に、エラー内容が `role="alert"` 等で即座にユーザーへ読み上げられること
- [ ] スクリーンリーダー利用時に、フォーカスを動かさなくてもバックグラウンド処理の進捗が自然に把握できること
