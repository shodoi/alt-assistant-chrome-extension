# 04: Gemini API 429レート制限の指数バックオフリトライと親切なエラー通知

**What to build:** 
Gemini API の呼び出し時に HTTP 429（Rate Limit / Quota Exceeded）が発生した場合、指数バックオフ＋ジッター（ランダム待機）を用いて最大3回まで自動で再試行する。また、再試行上限に達した場合や、APIキー未設定・無効（401/403）などのエラーが発生した場合に、不透明なシステムエラーではなく、ユーザーが次の行動（「オプション画面でAPIキーを再確認してください」「しばらく待ってから再実行してください」等）を起こせる明確な日本語メッセージをモーダルで表示する。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Gemini API から 429 エラーが返された際、即時失敗とせず指数バックオフ（例: 1秒、2秒、4秒＋ジッター）で自動再試行されること
- [x] 再試行中に成功した場合、ユーザー体験を損なうことなく正常にAltテキストが生成・表示されること
- [x] APIキーが無効または未設定の場合、「APIキーが無効です。オプション画面から設定を確認してください」と案内ダイアログが表示されること
- [x] ネットワーク切断やタイムアウト時にも、わかりやすい日本語のエラーメッセージが表示されること
