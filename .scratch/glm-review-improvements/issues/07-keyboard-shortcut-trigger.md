# 07: キーボードショートカット起動（chrome.commands）対応

**What to build:** 
マウスの右クリック（コンテキストメニュー）を操作できないキーボードユーザーやスクリーンリーダー利用者のために、`chrome.commands` API を利用してキーボードショートカット（例: `Alt+A` / macOS では `Option+A`）を定義する。Webページ上でフォーカスされている画像要素、またはカーソル下の画像に対して、キー入力一発でAltテキスト生成フローを直接起動できるようにする。

**Blocked by:** 02: ダイアログ・モーダルのフォーカストラップとキーボード操作性（A11y）向上

**Status:** completed

- [x] `manifest.json` に `commands` 定義が追加され、デフォルトのショートカットキー（例: `Alt+A` / `Option+A`）が設定されていること
- [x] ページ内の画像要素にフォーカスがある状態でショートカットキーを押すと、右クリック時と同様にAlt生成指示ダイアログが開くこと
- [x] `chrome://extensions/shortcuts` からユーザーがショートカットキーを自由にカスタマイズできること
- [x] 画像以外の要素にフォーカスがある場合にショートカットを押した際は、誤作動せず適切にガイド（「画像を選択してください」等の通知）が表示されるか安全に無視されること
