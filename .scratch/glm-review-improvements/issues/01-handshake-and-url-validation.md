# 01: SW–ContentScript間の通信健全化（PINGハンドシェイク & 画像URLバリデーション）

**What to build:** 
Webページ上の画像右クリックからAltテキスト生成を開始する際、Content Scriptがすでに読み込まれているかを事前にハンドシェイク（疎通確認）し、未注入時のみ動的ロードする。また、対象画像URLが安全なプロトコル（http:, https:, data:）であるかを厳格に検証し、悪意あるプロトコル（javascript:等）によるスクリプト実行や、二重ロードによるメッセージリスナー重複・レースコンディションを防止する。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 同一タブ上で複数回画像を右クリックしてAlt生成を開始しても、Content Scriptの二重注入やリスナー重複による多重メッセージ送信が発生しないこと
- [x] ページ読み込み直後や動的遷移直後でも、ハンドシェイクによって確実にContent Scriptとの通信が確立され、生成ダイアログが表示されること
- [x] `javascript:`、`file:`、`blob:` 等の危険または非想定なプロトコルの画像URLに対しては、処理を中断して安全にエラー通知されること
- [x] 正常な `http:`, `https:`, `data:image/...` の画像に対しては、従来どおり問題なく処理が進行すること
