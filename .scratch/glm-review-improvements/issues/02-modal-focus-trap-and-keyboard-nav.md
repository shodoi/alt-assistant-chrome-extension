# 02: ダイアログ・モーダルのフォーカストラップとキーボード操作性（A11y）向上

**What to build:** 
Altテキストの指示ダイアログおよび生成結果確認モーダルが表示された際、キーボード操作のフォーカスがモーダル内部の要素（入力欄、ボタンなど）のみを循環するように制限する（フォーカストラップ）。また、モーダル表示時に最初の操作要素へ自動フォーカスし、`Escape` キーでキャンセル・閉じる操作を可能にし、モーダルを閉じた際はトリガー元となった画像要素にフォーカスを復帰させる。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 指示入力ダイアログ表示時、最初の操作可能要素（テキストエリアまたは確定ボタン）に自動でフォーカスが当たること
- [ ] `Tab` キーおよび `Shift + Tab` キーを押した際、フォーカスがモーダル外（背景Webページ）へ抜けず、モーダル内をループすること
- [ ] モーダル表示中に `Escape` キーを押すと、キャンセル処理が実行されてモーダルがスムーズに閉じること
- [ ] モーダルが閉じた後、フォーカスが右クリックされた元の画像要素（または呼び出し元要素）に戻ること
- [ ] マウスを使用せずキーボードのみ（Tab、Enter、Escape）で、指示入力・生成確認・Alt反映の全フローを完結できること
